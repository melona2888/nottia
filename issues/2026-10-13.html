01 Icebreaker 선정 이유: 허위 정보 유통 경로

AI 가짜 글보다 더 위험한 것은 '진짜처럼 보이는 출처'였다

OpenAI는 러시아·이란 연계 세력이 가짜 연구기관과 기자 인물을 만들어 기존 매체에 콘텐츠를 싣는 두 영향력 공작을 차단했다고 밝혔습니다. AI는 글쓰기와 번역을 빠르게 했지만, 신뢰받는 유통 경로를 빌리는 오래된 전술이 여전히 핵심이었습니다.

가짜 기자 7명

이란 연계 공작은 일곱 명의 기자 인물을 꾸며 세계의 중소 온라인 매체에 장문 기사를 투고했습니다. 단순 소셜 댓글보다 실제 매체의 편집 절차를 통과하는 데 공을 들였습니다.

AI는 증폭기, 전술은 오래됐다

모델은 글쓰기·번역·내부 보고서 작성의 규모와 언어 완성도를 높였습니다. 그러나 가짜 인물, 허위 문서, 실제 조직을 가장하는 방식은 AI 이전에도 쓰이던 전술입니다.

출처 이름까지 확인

문장이 자연스럽다는 사실만으로 신뢰할 수 없습니다. 필자 이력, 매체 소유 관계, 다른 출처의 독립 확인이 콘텐츠 자체보다 중요해졌습니다.

영향 수치는 신중하게

OpenAI는 러시아 연계 공작을 Breakout Scale 5, 이란 연계 공작을 4로 평가했습니다. 다만 운영자들의 자체 성과 보고에는 과장된 주장도 있어 모두 사실로 볼 수는 없습니다.

02 Main 선정 이유: 대화형 인터페이스 전환

GPT-6, 답변 대신 그 자리에서 쓸 화면을 만든다

OpenAI는 GPT-6를 ChatGPT 무료·유료 사용자에게 확대하면서 Intelligent UI를 공개했습니다. 질문에 따라 텍스트뿐 아니라 표, 지도, 버튼, 입력 폼, 계산기 같은 상호작용 화면을 답변 안에서 바로 구성합니다.

질문마다 다른 화면

비교는 나란한 표로, 개념 설명은 조작 가능한 그림으로, 계산은 즉석 도구로 보여줄 수 있습니다. 단순 텍스트가 더 적합하면 기존 답변 형태를 유지합니다.

생성 중에도 먼저 보여준다

스트리밍 가능한 기본 컴포넌트와 컴파일러를 사용해 전체 답변이 끝나기 전에 화면을 점진적으로 표시합니다. 웹 검색 질문의 첫 응답은 GPT-5.6 Instant보다 평균 44% 빨랐다는 내부 평가가 제시됐습니다.

유료는 Sol, 무료는 Luna

Plus·Pro·Business·Enterprise에는 GPT-6 Sol, Free·Go에는 GPT-6 Luna가 적용됩니다. Enterprise는 관리자 설정에 따라 제공 여부가 달라집니다.

Chat만 바뀐다

이번 변경은 ChatGPT의 Chat 경험에 적용됩니다. Work와 Codex를 구동하는 모델은 이 발표로 바뀌지 않았고, 인터페이스 판단 품질도 계속 개선 중입니다.

02 Main 선정 이유: 고빈도 작업 비용

Claude Haiku 5.5, 반복 작업을 75% 낮은 비용으로 겨냥하다

Anthropic은 요약, 분류, 데이터베이스 질의, 브라우저 조작처럼 짧고 자주 반복되는 일을 위한 Claude Haiku 5.5를 출시했습니다. 큰 모델이 전체 작업을 이끌고 작은 모델이 하위 작업을 맡는 에이전트 구성을 분명한 사용처로 제시했습니다.

평균 실행 비용 75% 감소

Anthropic은 Haiku 4.5보다 평균 약 75% 낮은 비용이라고 설명합니다. 10만 토큰 이하 요청은 입력 100만 토큰당 0.10달러, 출력은 0.50달러입니다.

큰 모델의 보조 작업자

요약·압축·빠른 조회·서브에이전트처럼 범위가 좁은 작업에 맞습니다. 복잡한 장기 코딩은 Sonnet·Opus가 더 적합하다는 구분도 공식 문서에 명시됐습니다.

노력 수준을 조절

Haiku 계열 최초로 effort 설정을 지원해 비용과 지능의 균형을 고를 수 있습니다. 컴퓨터 사용과 브라우저 사용을 위한 Python·TypeScript SDK 지원도 beta로 추가됩니다.

주요 클라우드에서 즉시 제공

Claude Platform과 AWS, Google Cloud, Microsoft Azure에서 사용할 수 있습니다. 긴 프롬프트는 별도 가격 구간이며 벤치마크 수치는 공급사 평가입니다.

02 Main 선정 이유: 장시간 업무 에이전트

Gemini agent, 질문·업무·코딩을 하나의 작업자로 묶는다

Google Cloud는 질문 답변, 문서 작업, 미디어 생성, 코딩을 하나의 인터페이스에서 맡기는 Gemini agent를 발표했습니다. 사용자가 세부 절차보다 목표를 주면 클라우드에서 오래 실행하고, 필요한 도구와 하위 에이전트를 조합해 결과를 돌려주는 구조입니다.

노트북을 닫아도 계속

작업은 클라우드에서 실행되고 같은 기억과 문맥을 유지합니다. 몇 시간이나 며칠이 걸리는 업무도 장치가 바뀌거나 사용자가 자리를 비운 뒤 이어갈 수 있습니다.

임시 하위 에이전트를 구성

복합 업무에는 역할별 하위 에이전트를 만들고 순차·병렬로 조정합니다. 팀용 coworker agent는 자체 이메일·저장공간·조직 내 정체성을 갖고 공유받은 문맥만 봅니다.

모델과 에이전트를 분리

작업에 따라 Gemini 계열과 Claude 모델을 선택하거나 조합합니다. 기억·도구·데이터를 유지하면서 밑의 모델을 바꾸는 것이 핵심 설계입니다.

비용 상한에서 자동 정지

프로젝트별 AI 지출 상한에 닿으면 에이전트를 멈추고 관리자가 다시 시작할 수 있습니다. 금융·법률 특화 기능은 preview이며, 발표문만으로는 기능별 현재 접근 가능 요금제·지역을 모두 확인할 수 없습니다.

02 Main 선정 이유: 에이전트 추론 인프라

Maia 300, 에이전트의 긴 기억과 반복 추론을 칩부터 겨냥한다

Microsoft는 Maia 200을 실제 Copilot 서비스에 투입하고, 긴 문맥과 다단계 에이전트 작업에 맞춘 Maia 300을 2027년부터 배치하겠다고 발표했습니다. 모델 경쟁이 데이터센터의 전력·메모리·네트워크 설계로 내려가는 흐름입니다.

Maia 200은 이미 운영 중

Maia 200은 Microsoft Copilot과 MAI 모델 개발에 쓰이고 있습니다. GitHub Copilot과 Microsoft Foundry 지원은 2026년 말까지 확대할 계획입니다.

긴 문맥에 메모리를 집중

Maia 300은 긴 문맥, 메모리 집약 작업, 토큰을 연속 생성하는 추론을 겨냥합니다. 8개의 HBM4 스택과 18TB/s의 최대 메모리 대역폭을 제시했습니다.

전력당 토큰 40% 목표

실제 배치는 2027년

Maia 300은 아직 생산 서비스가 아닙니다. 2027년 배치를 시작할 예정이므로 실제 비용·성능은 운영 결과로 다시 확인해야 합니다.

03 Dev 선정 이유: 로컬 실행 권한

Copilot 로컬 샌드박스, AI가 만질 수 있는 범위를 정한다

GitHub Copilot의 로컬 샌드박스가 CLI, Copilot 앱, VS Code Agent Host 세션에서 정식 제공됩니다. 모델이 어떤 답을 내는지와 명령이 실제로 접근할 수 있는 파일·네트워크·자격증명을 분리해 관리합니다.

폴더마다 읽기·쓰기 제한

에이전트 명령이 읽거나 수정할 수 있는 파일과 디렉터리를 정책으로 좁힐 수 있습니다. 프로젝트 밖 자료를 실수로 건드리는 위험을 줄입니다.

네트워크와 자격증명도 분리

인터넷, 로컬 네트워크, Git 자격증명, GitHub CLI 자격증명 접근을 통제할 수 있습니다. MCP·언어 서버 같은 로컬 도구에도 지원 범위 안에서 적용됩니다.

Windows·macOS·Linux 공통 정책

Microsoft eXecution Container가 공통 정책을 운영체제의 실제 격리 기능으로 바꿉니다. 조직은 개발자가 약화할 수 없는 관리형 설정도 적용할 수 있습니다.

모델 선택과 권한은 별개

어떤 모델을 쓰더라도 도구 실행에는 같은 경계를 적용할 수 있습니다. 기능은 Copilot에 추가 비용 없이 포함됩니다.

03 Dev 선정 이유: 비밀정보 사전 차단

토큰처럼 생기지 않은 비밀번호도 코드 문맥으로 찾는다

GitHub는 주변 코드를 읽어 정형 패턴이 없는 비밀번호와 자격증명을 찾는 전용 모델을 공개했습니다. 커밋 뒤 경고뿐 아니라 push 전 차단과 Copilot 보안 리뷰로 탐지 지점을 넓히는 계획입니다.

문자열 주변 문맥을 읽는다

고정 접두사가 있는 API 키만 찾는 대신 변수명과 사용 위치를 보고 자격증명 가능성을 판단합니다. 코드를 생성하지 않고 탐지 분류에 집중한 모델입니다.

기존 알림은 자동 교체

AI-detected Password alerts 사용자는 새 모델로 자동 전환됩니다. GHSP·GHAS 고객의 기존 경고 스캔은 추가 비용 없이 유지됩니다.

push 차단은 아직 preview

AI push protection은 private preview이고, Copilot의 `/security-review` 비밀정보 검사는 곧 private preview로 제공될 예정입니다. 둘 다 기본값은 꺼져 있습니다.

검사해도 비용이 생길 수 있다

새 opt-in 검사는 AI Credits를 소비하며, push를 막지 않은 검사도 과금될 수 있습니다. 관리자는 활성화 전에 정책과 예산 상한을 확인해야 합니다.

03 Dev 선정 이유: 로컬 모델 선택

Copilot CLI에서 Ollama 로컬 모델을 바로 고른다

GitHub Copilot CLI 1.0.94-0부터 `/model` 명령이 실행 중인 Ollama의 지원 모델을 찾아 클라우드 모델과 함께 보여줍니다. 같은 개발 흐름 안에서 작업 성격과 데이터 조건에 맞춰 모델을 바꾸기 쉬워졌습니다.

재시작 없이 모델 전환

발견된 모델의 제공자와 endpoint를 확인한 뒤 현재 세션에 추가해 바로 쓸 수 있습니다. 연결 실패 원인도 모델 선택 화면에 표시됩니다.

설치는 대신해주지 않는다

Ollama와 모델은 미리 설치하고 실행해야 합니다. 사용할 모델은 tool calling과 streaming을 지원해야 합니다.

로컬 선택이 곧 오프라인은 아니다

로컬 모델을 골라도 GitHub 텔레메트리가 자동으로 꺼지지 않습니다. 오프라인 모드는 별도 환경 변수로 명시해야 합니다.

원격 제공자는 계속 원격

오프라인 모드에서도 원격 provider를 선택하면 프롬프트와 코드 문맥이 해당 endpoint로 전송될 수 있습니다. 모델 위치와 데이터 경로를 따로 확인해야 합니다.
