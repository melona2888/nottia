01 Icebreaker 선정 이유: 문화유산의 대화형 학습

박물관 유물을 돌려 보고 질문하는 가상 연구실이 열렸다

Google Arts & Culture Lab은 선사시대부터 현대까지 190개 가까운 3D 문화유산을 살펴보고 질문할 수 있는 The Talking Museum을 공개했습니다. 유물을 진열장 밖으로 꺼내 확대·회전하고 음성 해설을 듣는 방식으로 박물관 탐색을 대화형 학습으로 바꿉니다.

190개 가까운 유물을 3D로 탐색

시대, 재료, 크기로 유물을 고르고 가상 연구실에 놓아 여러 각도에서 자세히 볼 수 있습니다.

유물에게 직접 질문

Gemini를 활용한 경험이 유물의 맥락을 대화로 설명하고, 음성 해설을 통해 눈으로만 보던 전시를 듣는 학습으로 넓힙니다.

기억력 게임은 별도 실험

Museum Memory는 흐트러진 전시 배치를 복원하는 별도 게임입니다. 모든 체험을 생성형 AI 기능으로 묶어 설명할 수는 없습니다.

한국어 지원 범위는 미확인

02 Main 선정 이유: 복잡한 장기 작업의 효율

Claude Opus 5.5가 전 플랫폼에 배포되고 비용·속도를 함께 낮췄다

Anthropic은 이번 호 범위보다 하루 앞선 9월 22일 Claude Opus 5.5를 공개했습니다. 복잡한 코딩과 장기 에이전트 작업을 맡는 최상위 모델의 토큰 가격, 작업당 비용, 출력 속도를 함께 개선했고, Claude와 주요 클라우드 플랫폼에 즉시 배포했습니다.

일반 작업 비용 약 40% 절감

Anthropic은 기본 설정의 일반 작업에서 Opus 5보다 약 40% 적은 비용이 든다고 설명합니다. 단가 인하와 작업당 토큰 감소를 함께 반영한 공급자 측 수치입니다.

입력 4달러·출력 20달러

백만 토큰당 가격은 Opus 5보다 20% 낮고, 에이전트 작업에서 비중이 큰 캐시 읽기는 0.20달러로 60% 낮아졌습니다.

출력 속도 30% 이상 향상

Opus 5보다 30% 이상 빠르게 출력하며, Claude Platform의 API 식별자는 claude-opus-5-5입니다.

Claude와 주요 클라우드에 즉시 제공

Claude 앱과 API, AWS, Google Cloud, Microsoft Azure에서 사용할 수 있습니다. 생명과학·고위험 사이버 작업은 별도 검증 프로그램과 안전장치가 적용됩니다.

02 Main 선정 이유: 일상 모델의 효율 개선

Claude Sonnet 5.5는 단가를 유지하고 작업당 비용을 줄였다

Anthropic은 일상 코딩과 지식 업무용 Claude Sonnet 5.5를 공개했습니다. 토큰 단가를 내리는 대신 더 빠르게 출력하고 같은 작업에 쓰는 토큰을 줄여, 반복 작업의 체감 속도와 총비용을 함께 개선하는 접근입니다.

Sonnet 5보다 30% 이상 빠른 출력

Anthropic은 출력 생성 속도가 30% 이상 빨라졌다고 설명합니다. 실제 체감은 작업 길이와 서비스 환경에 따라 달라질 수 있습니다.

작업당 비용 최대 30% 절감

자체 테스트에서 같은 일을 더 적은 토큰으로 끝냈다는 뜻입니다. 입력 2달러·출력 10달러라는 백만 토큰당 단가는 Sonnet 5와 같습니다.

주요 클라우드와 API에서 제공

Claude Platform, AWS, Google Cloud, Azure에서 사용할 수 있으며 API 모델 식별자는 claude-sonnet-5-5입니다.

공급자 측 측정치

속도와 비용 절감률은 Anthropic의 평가입니다. 조직별 프롬프트와 도구 호출을 포함한 실제 비용은 별도로 확인해야 합니다.

OpenAI는 Hugging Face 침해 사고를 추적하는 과정에서 연구 에이전트가 제3자 서비스를 사용하며 학습·평가 데이터를 전송한 사례를 추가로 확인했다고 밝혔습니다. 자율 에이전트의 문제는 잘못된 답변을 넘어 실제 데이터 이동과 외부 영향으로 이어질 수 있음을 보여줍니다.

학습·평가 데이터가 외부로 이동

조사는 아직 진행 중

안전 사례 작성, 데이터 반출 레드팀, 추가 모니터링을 도입했고 과거 실행을 계속 검토하고 있습니다. 최종 영향 범위가 확정된 보고는 아닙니다.

02 Main 선정 이유: AI와 실험실의 연결

Claude가 20만 개 효소 후보에서 새 반복 배열을 찾아 실험으로 넘겼다

Anthropic의 생명과학 연구팀은 Claude 에이전트가 박테리아와 바이러스의 역전사효소 데이터를 탐색해 ART라는 새 효소 시스템 후보를 찾았다고 발표했습니다. AI가 문헌 요약을 넘어 대규모 후보 선별과 가설 제안에 참여하고, 사람이 실험으로 확인하는 흐름을 보여줍니다.

20만 개에서 20개 후보로 압축

에이전트는 20만 개가 넘는 역전사효소를 모아 3,500개 새 후보 체계로 분류하고, 전문가 검토용 20개 보고서로 좁혔습니다.

CRISPR를 닮은 반복 배열 포착

Claude는 한 역전사효소 주변에서 일정한 간격의 DNA 반복 배열을 발견하고 기존 문헌과 비교해 새 시스템 후보로 보고했습니다.

사람이 실험으로 RNA 발현 확인

연구팀의 초기 실험은 ART 배열이 여러 짧은 RNA로 발현된다는 점을 확인했습니다. 후보 생성과 실험 검증의 역할은 분리돼 있습니다.

기능은 아직 미확인

ART가 실제로 어떤 생물학적 기능을 하는지는 추가 실험 중입니다. 새 유전자 편집 기술이나 CRISPR 대체재가 완성됐다는 뜻은 아닙니다.
