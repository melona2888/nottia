Nottia Weekly Newsletter / 16호 2026.09.09 - 2026.09.15

AI가 데스크톱과 데이터, 음성으로 실행 범위를 넓힌 주

Gemini는 Windows 작업 화면에 들어왔고, Data agent와 GPT‑Live‑1은 기업 데이터와 실시간 대화를 실제 행동에 연결하기 시작했습니다. 동시에 Agents API와 위협 보고서는 AI가 만든 결과보다 권한·검증·중단 경계가 더 중요해졌음을 보여줬습니다.

This Week in 4 Lines

  1. AI 창작은 화면 속 생성 버튼을 넘어, 관객이 음악·그림·게임에 직접 참여하는 공공 전시로 확장됐습니다.
  2. Gemini와 Data agent는 별도 도구를 오가는 대신 데스크톱과 회사 데이터 안에서 질문부터 실행까지 잇기 시작했습니다.
  3. GPT‑Live‑1은 듣기와 말하기를 동시에 처리하며, 음성 대화와 더 깊은 추론·도구 실행을 한 흐름으로 연결했습니다.
  4. Agents API와 Copilot은 장기 실행·모델 선택·리뷰 검증을 제품화했지만, 위협 사례는 승인과 감사가 함께 가야 한다고 경고합니다.

Editorial Note

이번 주의 공통점은 AI가 답을 잘 쓰는 단계에서 실제 환경을 움직이는 단계로 넘어갔다는 것입니다. 작업 화면, 사내 데이터, 실시간 음성, 코드 저장소가 모두 실행면이 됐습니다. 이제 제품의 차이는 모델 점수만이 아니라 어떤 데이터에 접근하고, 어떤 행동 전에 멈추며, 결과를 어떻게 다시 확인하게 하는지에서 더 선명해집니다.

02 Main 선정 이유: 데스크톱 진입

Gemini가 Windows 작업 화면 위에서 바로 불리는 데스크톱 앱이 됐다

Google은 9월 10일 Windows 10·11용 Gemini 앱을 전 세계에 공개했습니다. 브라우저 탭을 옮기지 않고 현재 작업 위에서 호출하고, 별도 공간에서는 Google 앱과 연결된 긴 작업까지 이어가는 두 가지 사용 흐름을 마련했습니다.

Alt + Space로 현재 화면 위 호출

문서 사실 확인이나 발표 제목 아이디어처럼 짧은 도움은 작업 앱을 떠나지 않고 바로 요청할 수 있습니다.

Gmail·Drive 문맥을 한 작업 공간에

전용 앱에서는 Google 앱의 정보를 불러와 요약하고, Gemini Spark에 여러 단계 작업을 넘길 수 있습니다.

이미지와 영상 생성도 데스크톱에서

Nano Banana 이미지와 Gemini Omni 영상 생성을 같은 앱에서 사용할 수 있어 창작 흐름의 이동을 줄입니다.

앱은 전 세계, 기능은 조건별

앱은 Windows 10·11에 공개됐지만 Spark와 일부 모델 기능은 구독·연령·지역 조건을 따로 확인해야 합니다.

02 Main 선정 이유: 자연어 데이터 분석

ChatGPT Work의 Data agent가 질문을 분석과 대시보드까지 잇는다

OpenAI는 9월 10일 회사 데이터에 연결해 원인을 조사하고 공유 가능한 대시보드를 만드는 Data agent를 공개했습니다. 핵심은 자연어 질의 자체보다 조직이 이미 쓰는 지표 정의와 접근권한을 분석 흐름에 그대로 가져오는 데 있습니다.

데이터베이스와 문서를 함께 연결

Redshift, BigQuery, Databricks, Snowflake, MongoDB뿐 아니라 Google Drive와 SharePoint 문서도 분석 문맥에 넣을 수 있습니다.

회사 용어와 계산식을 먼저 이해

dbt와 시맨틱 레이어, BI 대시보드의 지표 정의를 활용해 같은 단어가 팀마다 다르게 계산되는 문제를 줄이려 합니다.

행·열 권한을 그대로 집행

관리자가 연결과 역할을 정하고, 질의는 연결된 계정의 테이블·행·열 수준 권한을 따릅니다.

좋은 답은 데이터 계약에 달렸다

자연어만으로 분석이 완성되는 것은 아닙니다. 데이터 품질, 지표 정의, 권한 설정이 결과의 신뢰도를 좌우합니다.

02 Main 선정 이유: 실시간 음성 실행

GPT‑Live‑1이 듣고 말하는 동안 더 깊은 작업을 뒤에서 이어간다

OpenAI는 9월 10일 GPT‑Live‑1을 API에 공개했습니다. 음성을 텍스트로 바꾼 뒤 다시 읽어주는 직렬 구조 대신 듣기와 말하기를 동시에 처리하고, 필요한 추론과 행동은 백엔드 모델과 도구에 넘기는 구조입니다.

말하는 중에도 듣는 풀듀플렉스

사용자가 중간에 끼어들거나 망설이고 말을 바꿔도 대화 흐름을 계속 따라가는 실시간 상호작용에 초점을 맞췄습니다.

깊은 일은 다른 모델과 도구에 위임

음성 모델은 대화를 유지하고, 검색·추론·에이전트 작업은 연결된 백엔드 모델과 하니스가 처리할 수 있습니다.

Full Duplex Bench 30%p 향상

OpenAI는 GPT‑Realtime‑2.1 대비 30%포인트 향상을 제시했습니다. 내부 평가이므로 실제 언어·소음 환경에서는 별도 확인이 필요합니다.

음성 전면부는 분당 0.05달러

API에서 오늘부터 쓸 수 있으며, 백엔드 모델과 도구 비용은 별도입니다. 언어·억양 선택지는 앞으로 더 확대될 예정입니다.

02 Main 선정 이유: 실제 악용의 실행 패턴

Anthropic 보고서는 AI 악용이 질문에서 다중 단계 운영으로 바뀌었다고 기록했다

Anthropic은 9월 10일 2025년 12월부터 2026년 8월까지 차단한 악용 사례를 공개했습니다. 보고서의 중요한 변화는 AI가 한 번의 답을 주는 도구가 아니라 정찰·침해·콘텐츠 배포를 연결하는 오케스트레이터로 쓰였다는 점입니다.

사이버부터 증류까지 7개 위험 영역

사이버 공격, 영향 공작, 감시, 사기, 생물학적 악용, 재래식 무기 개발, 모델 증류 사례를 구분했습니다.

도우미에서 오케스트레이터로

위험은 단일 취약점 생성보다 공격 전 과정의 속도·범위·깊이를 적은 인력으로 늘리는 데서 더 크게 나타났습니다.

차단 사례는 발생률 통계가 아니다

Anthropic이 가장 주목할 만하고 새로운 사례를 선별한 보고서입니다. 전체 악용 빈도나 Claude만의 고유 위험을 뜻하지 않습니다.

권한·탐지·공유를 함께 설계

계정 차단만이 아니라 관찰된 전술을 방어 장치에 반영하고 기관·업계와 정보를 공유하는 운영 루프가 강조됐습니다.

03 Dev 선정 이유: 에이전트 하니스의 API화

OpenAI Agents API가 Codex의 장기 실행 하니스를 개발자에게 열었다

OpenAI는 9월 10일 Codex의 문맥 관리·도구 사용·서브에이전트 조정을 관리형 API로 제공하는 Agents API를 공개 베타로 출시했습니다. 모델 호출보다 실행 환경과 복구 흐름을 직접 만들던 부담을 줄이는 데 초점이 있습니다.

작업·모델·도구·환경을 한 호출에

에이전트 정의와 입력을 묶어 세션을 만들고, OpenAI가 하니스의 실행과 개선을 관리합니다.

샌드박스 위치는 개발자가 선택

OpenAI 호스팅, 자체 인프라, 파트너 환경 중에서 파일·비밀·컴퓨팅 조건에 맞는 실행면을 고를 수 있습니다.

압축·도구 검색·서브에이전트 내장

여러 컨텍스트 창을 잇는 압축, 필요한 도구만 불러오는 검색, 병렬 하위 작업 조정을 기본 기능으로 제공합니다.

공개 베타, 토큰과 도구 비용은 별도

모든 개발자가 쓸 수 있고 API 추가 사용료는 없지만, 실제 모델 토큰과 외부 도구 비용은 지불해야 합니다.

03 Dev 선정 이유: 비용·품질 선택권

Copilot Auto가 모델 선택을 효율·균형·지능 세 단계로 나눴다

GitHub은 9월 14일 Copilot Auto 모델 선택에 세 가지 우선순위를 추가했습니다. 사용자는 모델 이름을 직접 고르지 않아도 비용과 지연시간, 품질 중 무엇을 더 중시할지 정하고 Auto가 프롬프트마다 모델을 고르게 할 수 있습니다.

효율·균형·지능으로 운영 목표 지정

빠르고 저렴한 경로, 비용과 품질의 절충, 어려운 작업의 품질 우선이라는 세 방향을 선택할 수 있습니다.

프롬프트마다 다른 모델을 선택

한 세션을 한 모델에 고정하지 않고 작업 난도와 선택한 목표에 따라 Auto가 실행 모델을 바꿉니다.

VS Code·CLI·Copilot 앱에 순차 배포

같은 운영 원칙을 편집기, 터미널, 독립 앱에 적용해 도구별 모델 선택 부담을 줄이려 합니다.

실제 과금은 선택된 모델 기준

‘지능’ 단계가 항상 가장 큰 모델을 뜻하지는 않습니다. 단순 작업에는 작은 모델을 고를 수 있고 비용도 결과 모델을 따릅니다.
