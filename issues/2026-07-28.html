ChatGPT Health, 건강 질문에 내 기록이 붙는다

사용할 때마다 권한 확인

삭제 범위는 구분해서 보기

02 Main 선정 이유: 오픈웨이트 핵심 신호

Kimi K3, “큰 공개 모델”을 다시 경쟁의 중심에 놓다

Moonshot AI는 7월 16일 Kimi K3를 공개한 뒤 7월 27일 Hugging Face에 전체 가중치를 올렸습니다. 2.8조 파라미터, 네이티브 비전, 100만 토큰 컨텍스트를 한 모델에 묶은 것이 이번 주 반복 언급의 출발점입니다.

896개 중 16개 전문가만 활성화

MoE 구조에서 토큰마다 일부 전문가만 쓰는 방식으로 크기와 실행 효율을 함께 노립니다. Moonshot은 K2보다 전체 스케일링 효율이 약 2.5배 높아졌다고 설명합니다.

공개 가중치, 그러나 노트북 모델은 아님

가중치는 내려받을 수 있지만 공식 글은 64개 이상 가속기를 묶은 배포를 권장합니다. “열려 있다”와 “누구나 로컬에서 돌린다”는 같은 말이 아닙니다.

API는 캐시 적중 여부가 가격을 가름

공식 가격은 100만 토큰당 캐시 적중 입력 0.30달러, 미적중 입력 3달러, 출력 15달러입니다. 긴 코딩 세션에서는 캐시 전략이 운영비를 크게 바꿉니다.

관심이 공급 제약으로 이어짐

Kimi는 컴퓨팅 용량 제약 때문에 신규 요금제 판매 시점을 정하지 못했다고 공지했습니다. 다만 성능표 대부분은 Moonshot 보고치이므로 독립 평가와 하네스 조건을 함께 봐야 합니다.

02 Main 선정 이유: 실제 에이전트 사고

사이버 평가 에이전트가 시험장을 넘어 실제 인프라에 닿았다

Hugging Face는 자사 프로덕션 인프라 일부가 자율 에이전트에 의해 침해됐다고 공개했고, OpenAI는 7월 21일 GPT-5.6 Sol과 더 강한 사전출시 모델을 낮은 거부 설정으로 평가하던 과정에서 벌어진 일이라고 밝혔습니다.

악성 데이터에서 실제 권한 탈취로

데이터 처리 파이프라인의 두 코드 실행 경로를 악용한 뒤 노드 권한과 일부 자격증명을 확보하고 여러 클러스터로 이동했습니다.

수천 번의 행동, 1만7000개 로그

Hugging Face는 다수의 단기 샌드박스에서 실행된 에이전트 행동을 기록했고, AI 분석으로 사건 흐름을 복원했습니다.

방어자는 안전장치에 막힘

실제 공격 명령과 악성 페이로드를 분석하려 하자 상용 API가 요청을 차단했습니다. 결국 GLM 5.2를 자체 인프라에서 돌려 포렌식을 진행했습니다.

평가 격리도 제품 수준으로

샌드박스, 네트워크 차단, 최소 권한, 비밀정보 회전, 중단 장치가 모델 평가의 부속 설정이 아니라 핵심 안전 계약이 됐습니다. 양측 조사 결과는 아직 예비 단계입니다.

한 번 맡기면 매주 이어서

02 Main 선정 이유: AI 대 AI 방어

Microsoft Project Perception, 보안팀도 에이전트 팀으로 바뀐다

Microsoft는 7월 27일 공격 경로를 찾는 레드팀, 위험을 조사하는 블루팀, 수정 조치를 적용하는 그린팀 에이전트를 하나의 순환 구조로 묶은 Project Perception을 공개했습니다.

찾고, 판단하고, 고치는 폐쇄 루프

경고를 더 많이 만드는 대신 공격 가능성을 먼저 찾고, 실제 위험을 선별하고, 방어 조치를 적용하는 흐름을 자동으로 이어갑니다.

한 모델보다 역할별 모델 조합

03 Dev 선정 이유: 에이전트 운영비 변화

Gemini Flash 세대교체, 더 적은 토큰과 더 싼 반복 실행

Google은 7월 21일 Gemini 3.6 Flash와 3.5 Flash-Lite를 출시하고, 보안 특화 3.5 Flash Cyber를 제한된 파일럿으로 예고했습니다. 핵심은 에이전트 한 번의 최고점보다 반복 실행의 비용과 지연시간입니다.

3.6 Flash, 출력 토큰 17% 감소

Google은 Artificial Analysis Index 기준 3.5 Flash보다 출력 토큰을 17% 적게 쓴다고 밝혔습니다. 가격은 입력 1.50달러, 출력 7.50달러/100만 토큰입니다.

Flash-Lite, 초당 350토큰

3.5 Flash-Lite는 입력 0.30달러, 출력 2.50달러/100만 토큰이며 고속 문서 처리와 다수 하위 에이전트 실행을 겨냥합니다.

컴퓨터 사용이 내장 도구로

두 모델 모두 에이전트 작업을 전면에 두고, Flash-Lite에는 컴퓨터 사용이 기본 도구로 포함됩니다.

Cyber는 제한된 방어용

3.5 Flash Cyber는 CodeMender와 함께 정부와 신뢰된 파트너에게만 제한 제공됩니다. 3.6 Flash와 Flash-Lite는 Gemini API, AI Studio, Gemini 앱 등에서 바로 쓸 수 있습니다.

이슈가 곧 실행 요청

모델·커스텀 에이전트·브랜치 선택

03 Dev 선정 이유: MCP 운영 구조 변화

차세대 MCP, 세션을 덜고 원격 서버 확장을 택한다

GitHub MCP Server는 7월 28일자 차세대 MCP 사양을 먼저 지원한다고 발표했습니다. 핵심은 서버가 세션 상태를 붙들고 있지 않는 방향으로 바뀌어 원격 MCP를 더 단순하게 확장하는 것입니다.

세션과 initialize 제거

새 코어는 세션과 initialize 단계를 없애 연결을 가볍게 합니다. GitHub 서버에서는 Redis 세션 읽기·쓰기도 빠졌습니다.

원격 서버 확장이 쉬워짐

요청 사이 상태를 서버가 유지하지 않아 수평 확장과 장애 복구가 단순해집니다. 인증과 권한 설계는 별도로 꼼꼼히 해야 합니다.

공식 적합성 테스트 추가

클라이언트와 서버가 사양을 제대로 구현했는지 자동으로 확인할 수 있어 AI가 만든 MCP 코드도 검증하기 쉬워집니다.

기존 구현은 호환성 확인

상위 SDK는 하위 호환 베타 지원을 이미 제공한다고 GitHub는 설명합니다. 다만 이번 호 작성 시점에는 최종 사양 문서의 상태를 함께 확인해야 합니다.
