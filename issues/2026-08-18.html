AI가 답변을 넘어, 속도와 연결과 책임을 제품화한 주

한국에 들어온 ChatGPT 광고, 워터마크를 준비하는 Claude, 초당 750토큰을 겨냥한 GPT-5.6, 외부 서비스와 이어지는 Gemini까지. 이번 주 AI는 더 많은 일을 맡는 동시에 더 분명한 표시와 통제를 요구받았습니다.

This Week in 4 Lines

  1. ChatGPT 광고가 한국의 Free·Go 성인 이용자에게 시작됐고, 답변과 광고를 분리한다는 운영 원칙이 함께 제시됐습니다.
  2. Claude는 앞으로 출시할 모델의 텍스트와 파일에 기계가 읽을 수 있는 출처 표시를 넣겠다고 밝혔습니다.
  3. OpenAI와 Google은 각각 초고속 추론과 외부 앱 연결로 AI를 실시간 업무와 생활 서비스 안에 더 깊이 붙였습니다.
  4. Claude Code 세션끼리 메시지를 주고받고, 에이전트는 YouTube 자막을 읽으며, 워터마크와 제거 도구의 추격전도 시작됐습니다.

Editorial Note

이번 주의 공통점은 AI가 채팅창 안의 답변기에서 벗어났다는 점입니다. 세션은 서로 협업하고, 에이전트는 외부 콘텐츠를 읽으며, 생성물 표시와 제거 기술은 곧바로 맞물렸습니다. 기능이 넓어질수록 권한·출처·검증 경계도 더 중요해집니다.

01 Icebreaker 선정 이유: 한국 사용자 체감 변화

ChatGPT 광고, 한국에서도 무료 이용의 대가를 화면에 표시한다

OpenAI는 8월 11일 영국·멕시코·브라질·일본과 함께 한국에서 ChatGPT Ads를 시작했습니다. 로그인한 성인 Free·Go 이용자가 대상이며, 광고가 답변과 어떻게 분리되는지가 핵심 확인점입니다.

Free·Go 성인부터

광고는 로그인한 성인 Free와 Go 요금제에 적용됩니다. Plus·Pro·Business·Enterprise·Education은 현재 대상이 아닙니다.

답변과 후원을 시각적으로 분리

OpenAI는 광고가 답변에 영향을 주지 않고, 후원 콘텐츠를 별도 표시한다고 설명합니다. 실제 화면에서도 이 경계가 선명한지 지켜봐야 합니다.

대화 원문은 광고주에게 비공개

광고주는 채팅·기억·개인정보가 아니라 조회와 클릭 같은 집계 성과를 받습니다. 다만 광고 선택에는 대화 주제와 과거 상호작용이 쓰입니다.

민감 주제와 미성년자는 제외

18세 미만으로 알려지거나 추정되는 계정, 건강·정신건강·정치 같은 민감 영역 주변에는 광고를 표시하지 않는다고 밝혔습니다.

02 Main 선정 이유: AI 생성물 출처 표시

Claude, 새 모델의 텍스트에도 보이지 않는 워터마크를 넣는다

Anthropic은 EU AI Act의 투명성 요구에 맞춰 앞으로 출시할 Claude 모델의 생성 텍스트에 기계 판독용 워터마크를, 지원 파일에는 서명된 출처 메타데이터를 넣겠다고 밝혔습니다.

문장 자체에 보이지 않는 신호

텍스트 워터마크는 별도 라벨이 아니라 단어 선택 패턴에 신호를 심는 방식입니다. 읽는 사람에게는 보이지 않아도 탐지 도구가 확인할 수 있게 합니다.

파일에는 서명된 출처 기록

지원되는 이미지·파일에는 생성 출처를 나타내는 디지털 서명 메타데이터를 넣습니다. 파일이 변경되면 서명의 유효성도 달라질 수 있습니다.

새 모델부터, 기존 모델은 전환 중

앞으로 출시되는 지원 모델은 처음부터 표시를 적용하고, 기존 모델은 전환 기간에 순차 적용합니다. 모든 Claude 응답이 이미 표시된다는 뜻은 아닙니다.

워터마크 부재가 인간 작성 증명은 아님

편집과 재작성으로 신호가 약해질 수 있고 탐지 도구 공개도 남아 있습니다. 하나의 워터마크만으로 저자나 진위를 단정하면 안 됩니다.

02 Main 선정 이유: 실시간 추론 속도

GPT-5.6 Sol Ultrafast, 프런티어 모델을 초당 최대 750토큰으로

OpenAI는 Cerebras 기반 Ultrafast 서비스 등급을 공개했습니다. 표준 처리보다 최대 14배 빠른 GPT-5.6 Sol을 목표로 하며, 응답이 끝날 때까지 기다리기 어려운 실시간 업무를 겨냥합니다.

초당 최대 750 출력 토큰

OpenAI가 제시한 최대치는 표준 처리 대비 최대 14배입니다. 실제 속도는 요청 길이와 도구 호출, 사용 환경에 따라 달라질 수 있습니다.

작은 모델 대신 속도 등급을 선택

지금까지 실시간성을 위해 더 작은 모델을 쓰던 작업에서 같은 프런티어 모델의 빠른 처리 경로를 고르는 선택지가 생깁니다.

장애 대응과 음성 지원을 겨냥

로그·코드 변경을 즉시 분석하는 사고 대응, 대화 흐름을 끊지 않는 고객 지원과 음성 업무가 대표 사용 사례로 제시됐습니다.

초기 고객 프리뷰

현재는 OpenAI API의 제한된 고객 대상 미리보기입니다. 일반 접근 시점과 가격은 확정 공개 전까지 운영 계획에 넣기 어렵습니다.

02 Main 선정 이유: 소비자 에이전트 연결

Gemini, 질문에 답하는 앱에서 예약과 편집을 이어주는 허브로

Google은 Gemini에 생산성·예약·음악·생활 서비스 연결을 추가한다고 발표했습니다. 대화를 마친 뒤 다른 앱으로 옮겨가던 단계를 줄이고, 실제 행동까지 한 흐름에 묶는 방향입니다.

회의 요약과 웹사이트 편집

Granola·Otter.ai·Wix 연결은 회의 내용을 정리하고 웹사이트를 고치는 생산성 흐름을 Gemini 안에서 이어가도록 설계됐습니다.

식당·여행·티켓 예약

OpenTable, Ticketmaster, GetYourGuide 등과 연결해 검색 결과를 보는 데서 예약 행동으로 넘어갑니다. 서비스와 지역별 지원 범위는 다릅니다.

생활 서비스까지 권한 확대

음악 재생, 집 수리 전문가 찾기, 진료 예약 같은 작업이 포함됩니다. 연결이 늘수록 계정 권한과 데이터 공유 범위를 함께 확인해야 합니다.

앞으로 몇 주간 순차 배포

발표 즉시 모든 사용자와 국가에 열리는 기능은 아닙니다. 실제 노출 여부와 지원 파트너는 Gemini 연결 앱 설정에서 확인해야 합니다.

02 Main 선정 이유: 멀티모달 의료 연구

AMIE, 글로 묻는 의료 AI에서 실시간 영상 진료 연구로

Google Research와 DeepMind는 Gemini와 Project Astra 기반 AMIE가 영상·음성 신호를 해석하며 실시간 진료 대화를 진행하는 연구 결과를 공개했습니다. 아직 실제 환자 진료용 제품은 아닙니다.

기침·표정·움직임까지 본다

텍스트 병력만 읽는 대신 영상과 소리를 함께 보고, 눈에 보이는 불편이나 행동 신호를 진단 추론에 사용합니다.

가상 신체검사를 안내

멀티에이전트 구조가 환자에게 카메라 앞에서 수행할 동작을 안내하고, 그 결과를 실시간 대화에 반영합니다.

모의 진료에서 의사와 비교

환자 배우와 1차 진료 의사가 참여한 무작위 연구에서 병력 청취·진단·관리·소통 항목을 평가했습니다. 실제 임상 결과와는 구분해야 합니다.

현장 배포 전 검증이 더 필요

Google도 AMIE를 연구 시스템으로 명시했습니다. 안전성, 편향, 책임, 실제 환자 환경 검증 없이는 진료 대체로 볼 수 없습니다.

03 Dev 선정 이유: 세션 간 에이전트 협업

Claude Code 세션끼리 직접 메시지한다, AI가 AI에게 업무를 넘기는 기능

Claude Code v2.1.224에는 서로 다른 세션을 찾아 메시지를 보내는 교차 세션 통신이 추가됐습니다. 백엔드와 프런트엔드처럼 따로 일하던 Claude가 사람의 복사·붙여넣기 없이 진행 상황과 요청을 직접 주고받을 수 있습니다.

ListAgents로 다른 세션 발견

실행 중인 Claude Code 세션을 찾아 이름과 상태를 확인합니다. 여러 터미널과 프로젝트에 흩어진 에이전트를 협업 대상으로 묶는 출발점입니다.

SendMessage로 AI끼리 인계

한 세션이 다른 세션에 작업 결과, 의존성, 다음 요청을 보낼 수 있습니다. 긴 작업을 역할별 세션으로 나누고 다시 합치는 흐름이 쉬워집니다.

다른 기기의 세션에도 전달

공식 릴리스는 macOS와 Linux에서 다른 기기에 있는 세션까지 메시지를 보낼 수 있다고 설명합니다. 수신 세션과 네트워크 상태에 따라 전달 가능 여부는 달라집니다.

메시지가 사용자 권한은 아니다

교차 세션 메시지가 승인 권한까지 넘기는 것은 아닙니다. 권한 우회 모드의 수신 세션에는 승인 보류 규칙이 적용돼 에이전트 대화와 사용자 권한을 분리합니다.

보이지 않는 유니코드 문자, 특수 공백과 파일의 C2PA·EXIF·XMP 정보를 탐지·제거합니다. 이 부분은 입력과 출력 차이를 비교할 수 있는 결정적 처리입니다.

Claude 공식 탐지기는 아직 빈자리

표시와 제거의 군비 경쟁
