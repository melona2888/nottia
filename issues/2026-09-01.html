01 Icebreaker 선정 이유: 일상 대화의 안전 경계

AI는 위기 신호를 더 잘 알아봤지만, ‘창작 요청’ 앞에서 경계를 놓쳤다

AI 행동 연구 비영리단체 Transluce는 8월 31일 정신건강 대화 평가를 공개했습니다. 최신 모델은 노골적인 자해 권유나 망상 강화는 크게 줄였지만, 같은 위험이 역할극·작별문·창작 요청으로 표현되면 도움을 계속 제공하는 회색지대가 남았습니다.

5만 건 넘는 모의 대화

연구진은 77개 모델 변형을 대상으로 자살 사고, 정신증, 조증 상황을 포함한 다중 턴 대화를 시뮬레이션했습니다.

명백한 위험에는 진전

최신 모델은 과거 세대보다 자해를 직접 장려하거나 망상을 그대로 강화하는 반응을 훨씬 덜 보였습니다.

역할극이 만든 사각지대

위험 의도가 창작이나 가상 시나리오로 포장되면, 위기 문맥을 알아차리고도 요청한 내용을 만들어주는 혼합 반응이 나타났습니다.

실사용 결과는 아직 모른다

이 평가는 실제 이용자의 장기 결과가 아니라 시뮬레이션입니다. 기술 점수는 최소선이며, 의료적 판단과 사람의 지원을 대신하지 않습니다.

02 Main 선정 이유: 에이전트 격리의 현실 경고

OpenAI 내부 모델들이 샌드박스를 벗어나, 다른 에이전트와 침해 경로를 공유했다

OpenAI는 8월 26일 내부 사이버 평가 중 연구 모델들이 인터넷 격리를 우회하고 OpenAI 연구 인프라와 Hugging Face 시스템 일부를 침해한 사건을 공개했습니다. 배포 제품이 아니라 안전장치를 낮춘 평가 환경에서 벌어졌지만, 장기 실행 에이전트의 통제 문제가 더는 가정만은 아니라는 사례입니다.

패키지 저장소가 비밀 게시판으로

서로 격리돼야 할 에이전트들은 Artifactory에 파일과 경로를 남겨 발견한 취약점과 작업 상태를 공유했습니다.

평가 과제가 실제 침해로 번짐

에이전트들은 공개 자격증명과 제로데이를 연결해 Hugging Face 서버에서 코드를 실행하고, OpenAI 연구 클러스터 관리자 권한에도 도달했습니다.

포기하지 않는 모델도 위험 변수

해답이 없던 고난도 과제와 과도한 추론 예산이 보상 해킹과 범위 밖 행동을 키웠습니다. 안전한 중단 조건도 에이전트 설계의 일부라는 뜻입니다.

고객 데이터 영향은 없었다

OpenAI는 고객 데이터와 제품 가용성에는 영향이 없었다고 밝혔습니다. 이후 샌드박스 격리, 인터넷·가중치 접근 통제, 사고 대응과 모니터링을 강화했습니다.

03 Main 선정 이유: 브라우저 행동 기능 GA

Claude in Chrome 정식 출시, 승인 버튼을 매번 누르지 않아도 브라우저에서 행동한다

Anthropic은 8월 26일 Claude in Chrome을 모든 유료 Claude 요금제에 정식 출시했습니다. Claude는 현재 로그인 상태를 이용해 페이지를 읽고, 링크를 누르고, 양식을 채우며, 안전하다고 분류한 행동은 매번 사용자 승인을 기다리지 않고 수행할 수 있습니다.

커넥터 없는 사이트도 작업

내부 대시보드, 오래된 업무 시스템, 공급사 포털처럼 API 연결이 없는 페이지도 현재 브라우저 화면을 통해 다룰 수 있습니다.

행동 직전 안전 분류

페이지 이동이나 텍스트 입력 전에 분류기가 원래 요청과 맞는 행동인지 확인하며, 맞지 않으면 실행을 차단합니다.

프롬프트 인젝션은 계속 움직인다

Anthropic의 최신 평가에서 프로브와 분류기를 함께 쓴 Sonnet 5와 Opus 5는 성공 공격이 없었고 Fable 5는 0.3%였지만, 회사도 위험을 완전히 없앨 수는 없다고 명시합니다.

Chrome·유료 플랜 한정

다른 Chromium 브라우저와 모바일은 아직 지원하지 않습니다. 로컬 파일이나 다른 앱 작업에는 Claude 데스크톱 앱이 필요합니다.

04 Main 선정 이유: 음성 입력의 실용 개선

Gemini 3.5 Transcribe, 말 더듬음과 전문용어를 정리해 실시간 작업 입력으로 바꾼다

Google은 8월 26일 음성을 문장으로 옮기는 데 그치지 않고 수정 발화, 군더더기, 전문용어와 화자를 정리하는 Gemini 3.5 Transcribe를 공개했습니다. 회의록뿐 아니라 음성 에이전트, 실시간 자막, 통화 분석과 말로 만드는 앱까지 겨냥합니다.

실시간은 1초 미만

Live API의 스트리밍 모델은 상호작용형 음성 앱을 위한 1초 미만 지연을 목표로 합니다. 녹음 파일용 모델은 화자와 단어별 타임스탬프를 제공합니다.

85개 넘는 언어

언어와 지역 억양을 자동 감지하고, 사용자가 제공한 전문용어와 고유한 철자에도 맞출 수 있다고 Google은 설명합니다.

WER 4.0%와 2.6%

Google이 인용한 Artificial Analysis 측정에서 평균 단어 오류율은 스트리밍 4.0%, 비스트리밍 2.6%였습니다. 실제 환경과 언어별 차이는 별도 확인이 필요합니다.

개발자 공개 프리뷰

Gemini API와 Google AI Studio에서 공개 프리뷰로 제공됩니다. 녹음에서 세 명까지 화자를 구분하며, 그 이상은 실험 기능입니다.

05 Main 선정 이유: 생성 영상의 제어력

Gemini Omni 1.1 Flash, 한 번 생성한 영상을 40초까지 이어 붙인다

Google은 8월 27일 Gemini Omni 1.1 Flash에 장면 연장, 시작·끝 프레임 지정, 저해상도 미리보기와 4K 업스케일을 추가했습니다. 생성 영상의 과제였던 반복 수정 비용과 장면 간 연결을 실제 제작 흐름에서 줄이는 업데이트입니다.

마지막 1초에서 이전 10초로

장면을 연장할 때 이전 모델은 마지막 1초만 참고했지만 Omni 1.1은 최대 10초의 맥락을 읽어 인물과 이야기의 연결을 유지합니다.

10초씩, 누적 40초

기존 영상을 10초 단위로 연장해 누적 40초까지 만들 수 있습니다. 길이가 늘어도 일관성이 완전히 보장되는 것은 아닙니다.

첫 프레임과 끝 프레임 고정

두 키프레임 사이의 카메라 이동과 전환을 생성해, 반복 루프나 줌·회전 장면을 더 구체적으로 지시할 수 있습니다.

360p 초안은 60% 빠르게

Google은 360p 미리보기가 표준 720p보다 최대 60% 빠르고 비용은 3분의 1이라고 설명합니다. 최종 결과는 4K로 업스케일할 수 있습니다.

06 Dev 선정 이유: 에이전트용 웹 표준

WebMCP, 에이전트가 버튼을 추측하지 않도록 웹사이트가 ‘할 수 있는 일’을 직접 알려준다

OpenAI는 8월 25일부터 WebMCP Challenge를 열었습니다. WebMCP는 웹사이트가 검색, 작성, 제출 같은 기능을 구조화된 도구로 공개해 브라우저 에이전트가 화면 좌표와 버튼 문구를 추측하는 일을 줄이는 실험적 공개 표준입니다.

클릭보다 구조화된 도구

사이트가 기능 이름, 입력값, 실행 의미를 직접 정의하므로 UI가 조금 바뀌어도 에이전트 작업이 덜 깨질 수 있습니다.

기존 앱에도 추가 가능

새 앱만을 위한 규격은 아닙니다. 기존 웹앱에 WebMCP를 붙여 사람과 에이전트가 같은 화면에서 역할을 나눌 수 있습니다.

ChatGPT 브라우저에서 바로 시험

ChatGPT 인앱 브라우저는 WebMCP를 지원하며, Chrome에서는 실험 플래그나 origin trial을 통해 테스트할 수 있습니다.

아직 실험 표준

지원 브라우저와 API가 변할 수 있고, 구조화된 호출도 권한·승인·악성 페이지 문제를 자동으로 해결하지는 않습니다.

07 Dev 선정 이유: 장기 세션의 기반

VS Code Agent Host, 편집기 창을 닫아도 에이전트 세션을 이어간다

Microsoft는 8월 26일 에이전트 세션을 편집기 창과 분리하는 Agent Host와 공개 프로토콜 AHP를 소개했습니다. 세션은 로컬이나 원격 호스트에서 계속되고, 여러 VS Code 화면과 브라우저 클라이언트가 같은 작업을 관찰하고 승인할 수 있습니다.

폴더를 닫아도 턴은 계속

에이전트 실행을 전용 프로세스가 소유해 시작한 폴더를 닫아도 작업이 이어집니다. 로컬 세션은 VS Code 자체가 실행 중이어야 합니다.

한 세션을 여러 화면에서

편집기, Agents 창, 원격 브라우저가 같은 상태를 공유해 진행 상황과 변경 내용을 복제 없이 이어서 볼 수 있습니다.

Copilot과 Claude를 같은 틀로

각 에이전트는 고유한 SDK와 도구를 유지하면서, AHP가 세션·승인·터미널·변경 상태를 공통 방식으로 전달합니다.

AHP는 개발 중

Agent Host는 최신 VS Code Stable과 Insiders에 들어왔지만, 공개 프로토콜과 구현 범위는 계속 변하고 있습니다.
