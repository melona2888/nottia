01 Icebreaker 선정 이유: 음성 에이전트 제품화

xAI Voice Agent Builder 베타, 전화 상담원을 노코드 빌더로 만든다

xAI는 Grok Voice 기반 Voice Agent Builder 베타를 공개했습니다. 핵심은 STT-LLM-TTS를 이어 붙이는 개발자 데모가 아니라, 전화번호, 지식베이스, 도구 호출, 가드레일, 통화 로그까지 한 제품 안에서 세팅하는 음성 에이전트 빌더입니다.

2분 안에 설정

xAI는 베타 빌더에서 자연어로 흐름을 설명하고 문서·도구·가드레일을 붙이면 개인화된 voice agent를 만들 수 있다고 설명합니다.

전화와 WebSocket

무료 번호를 받거나 기존 번호를 SIP로 가져올 수 있고, 자체 클라이언트는 WebSocket으로 붙일 수 있습니다. 상담·예약·주문조회 같은 표면이 바로 대상입니다.

도구와 MCP

캘린더, 이메일, API, 환불·주문 상태 조회, Notion·Linear, 파일, 사람 상담원 이관까지 도구 연결을 전면에 둡니다. 음성이 새 UI가 되는 흐름입니다.

분당 과금

공개 가격은 오디오 분당 0.05달러, 무료 번호 telephony 분당 0.01달러입니다. 음성 에이전트가 SaaS 기능보다 사용량 기반 운영비로 읽히는 지점입니다.

02 Main 선정 이유: 재오픈과 안전장치

Claude Fable 5 재오픈, 모델 출시가 정책·안전장치 이벤트가 됐다

Anthropic은 6월 12일 수출통제 여파로 중단했던 Claude Fable 5 접근을 7월 1일부터 전세계 사용자에게 복구한다고 밝혔습니다. 이 소식은 단순한 모델 재오픈이 아니라, 고성능 모델 출시가 정부 정책, 클라우드 배포, 사이버 안전장치와 함께 움직인다는 사례입니다.

7월 7일까지 포함 사용

02 Main 선정 이유: 과학 워크벤치

Claude Science, 과학자의 터미널·노트북·문헌 작업을 한 세션으로 묶는다

Anthropic은 과학자를 위한 Claude Science 베타를 공개했습니다. PubMed, Jupyter, R, 클러스터 터미널, 구조·분자 시각화처럼 흩어진 도구를 하나의 연구 세션으로 묶고, 생성물마다 재현 가능한 코드와 이력을 남기는 방향입니다.

macOS·Linux·SSH

Claude Science는 로컬 macOS/Linux, 원격 머신, HPC login node에서 쓸 수 있습니다. 민감한 대형 데이터가 기존 연구 인프라에 남는 설계입니다.

60개 이상 과학 skill

유전체, single-cell, proteomics, 구조생물학, cheminformatics 같은 영역별 커넥터와 skill이 기본 구성됩니다. 범용 챗봇보다 실험실 도구에 가깝습니다.

Reviewer agent

별도 reviewer agent가 citation, 계산, 그림과 코드의 불일치를 점검합니다. 과학용 AI에서 중요한 것은 답변보다 audit trail입니다.

03 Dev 선정 이유: 토큰 비용 구조 변화

DeepSeek V4, 피크타임 할증으로 AI 토큰도 시간대 비용이 됐다

DeepSeek의 V4 전환은 단순한 모델 교체나 할인 종료로만 보면 아깝습니다. 핵심은 피크타임 요금을 2배로 올리는 방식의 할증제가 붙으면서, AI 토큰 비용도 클라우드 컴퓨팅이나 전력요금처럼 “언제 쓰느냐”에 따라 달라지는 운영비가 됐다는 점입니다.

피크타임 2배 인상

V4에 맞춰 피크타임 단가가 올라가면, 같은 프롬프트와 같은 모델도 호출 시간에 따라 비용이 달라집니다. 대량 배치·요약·인덱싱 작업은 시간 예약의 가치가 생깁니다.

토큰도 수요관리 대상

AI 비용 최적화는 “더 싼 모델 고르기”에서 끝나지 않습니다. 피크 회피, 캐시율, batch window, priority queue가 제품 원가에 직접 들어옵니다.

긴 컨텍스트의 원가

DeepSeek 공식 가격표는 V4-Flash와 V4-Pro 모두 1M context, 최대 384K output을 내세웁니다. 긴 컨텍스트가 기본값이 될수록 시간대별 단가 차이는 더 크게 체감됩니다.

04 Research 선정 이유: 제품 뒤의 연구 흐름

이번 주 연구 노트: RL 안정화, 로봇 런타임, 생성 모델 압축, VLM 데이터

이번 주 HF Daily Papers는 에이전트 학습과 배포의 현실적인 병목을 많이 다룹니다. 훈련과 추론의 불일치, 로봇의 closed-loop 실행, diffusion quantization, 로봇 행동 보정, VLM 데이터 구성처럼 제품화 전에 부딪히는 문제들입니다.

MIPU: 추론 정책이 좋아져야 함

LLM RL에서 training engine과 inference engine의 확률 불일치가 정책 붕괴를 부른다는 문제를 다룹니다. 실제 배포 정책 개선을 목표로 업데이트를 선별합니다. HF Papers

Embodied.cpp: 로봇용 C++ 런타임

VLA와 world-action model을 로봇·시뮬레이터·엣지 장치에 올리기 위한 portable runtime입니다. closed-loop와 batch-1 latency를 일반 서버와 다른 계약으로 봅니다. HF Papers

OrbitQuant: diffusion을 낮은 비트로

이미지·비디오 diffusion transformer의 timestep별 activation drift를 calibration 없이 다루는 PTQ 접근입니다. FLUX.1, Wan 2.1, CogVideoX 등에서 저비트 압축을 겨냥합니다. HF Papers

VLA-Corrector: 행동 chunk를 끊고 다시 계획

로봇이 예측한 행동 묶음을 맹목적으로 끝까지 실행하지 않도록, latent vision monitor가 drift를 감지하면 stale action을 버리고 보정 계획을 호출합니다. HF Papers

DataComp-VLM: 필터보다 혼합

160개 dataset과 6T multimodal tokens로 VLM 데이터 큐레이션을 비교합니다. 연구진은 filtering보다 instruction-heavy data mixing이 더 큰 개선을 냈다고 보고합니다. HF Papers
