01 Icebreaker 선정 이유: 비개발자 체감

Meta Brain2Qwerty, 수술 없이 뇌 신호를 문장으로 복원하는 길을 넓힌다

Meta는 Brain2Qwerty v2를 공개하며 비침습 뇌 기록에서 문장을 디코딩하는 성능을 크게 끌어올렸다고 설명했습니다. 아직 제품이 아니라 연구 성과지만, 의사소통이 어려운 사람을 위한 AI 보조 기술이 어디로 가는지 보여주는 강한 신호입니다.

수술 없는 뇌-문장 디코딩

MEG 장비를 쓴 참가자의 뇌 신호를 원시 신호부터 끝까지 학습해 문장으로 복원합니다. 침습형 임플란트가 아니어서 확장 가능성에 초점이 있습니다.

61% 단어 정확도

Meta는 v2가 평균 61% 단어 정확도, 최고 참가자에서는 78%를 달성했다고 밝혔습니다. 기존 비침습 방식의 8%와 비교해 큰 차이를 제시했습니다.

LLM이 잡음과 의미를 잇는다

신경 데이터에 맞춘 언어모델 미세조정으로 잡음 많은 신호와 coherent language 사이의 간격을 줄였습니다. AI 에이전트도 디코딩 파이프라인 최적화 탐색에 쓰였습니다.

의료 제품은 아직 아님

연구 코드와 데이터 공개가 핵심이며, 실제 보조기기로 쓰려면 장비, 반복성, 안전성 검증이 더 필요합니다. 숫자는 실험 조건 안에서 읽어야 합니다.

02 Main 선정 이유: 개인 맥락

Gemini, Google Photos와 개인 앱 맥락을 이미지 생성에 연결한다

Google은 미국의 eligible 사용자에게 Gemini의 개인화 이미지 생성을 무료로 확장했습니다. 사용자가 허용하면 Gmail, Google Photos, YouTube, Search 같은 맥락을 이용해 프롬프트에 일일이 설명하지 않아도 개인 취향과 생활 맥락이 반영된 이미지를 만들 수 있습니다.

사진 업로드를 줄임

예를 들어 “나와 내가 좋아하는 것들의 일러스트”처럼 요청하면 Google Photos에서 관련 맥락을 가져올 수 있습니다. 반복 업로드보다 연결된 앱 맥락을 활용하는 방향입니다.

Nano Banana와 Personal Intelligence

Google은 Personal Intelligence를 Nano Banana와 Google Photos에 연결한다고 설명했습니다. 생성 모델의 품질보다 개인 맥락 연결이 이번 변화의 핵심입니다.

미국 eligible 사용자부터

공개 범위는 eligible users in the U.S.로 제한됩니다. 지역, 계정, 앱 연결 조건을 확인해야 같은 경험을 기대할 수 있습니다.

옵트인과 설정이 관건

Google 앱 연결은 사용자가 허용하는 방식이며 설정에서 조정할 수 있습니다. 개인화가 강해질수록 어떤 앱을 연결할지 판단이 더 중요해집니다.

02 Main 선정 이유: 에이전트 API 표준

GPT-5.6, 공개 출시가 아니라 ‘정부 검토형 제한 프리뷰’로 보인다

공식 API 최신 모델 문서에는 여전히 `gpt-5.5`가 표시되지만, Axios와 Business Insider 등은 GPT-5.6이 Sol·Terra·Luna 세 모델로 제한 프리뷰에 들어갔다고 보도했습니다. 독자가 기억할 점은 “쓸 수 있는 새 모델”보다 “프런티어 모델 공개가 정부 검토와 접근 승인 문제로 바뀌고 있다”는 신호입니다.

Sol·Terra·Luna 3단 구성

보도들은 GPT-5.6이 고성능 Sol, 균형형 Terra, 빠르고 저렴한 Luna로 나뉜다고 전합니다. 다만 공개 API 문서에 정식 모델 슬러그로 올라온 상태는 아닙니다.

소수 파트너만 접근

Axios는 정부가 승인한 소규모 파트너에게만 제한 프리뷰가 열린다고 보도했습니다. Business Insider도 미국 정부 요청에 따라 신뢰 파트너부터 시작한다고 전했습니다.

사이버·바이오·장기 에이전트

The Verge 보도는 Sol이 코딩, 사이버보안, 생물학, long-horizon agentic tasks에 초점을 둔다고 전했습니다. 그래서 출시 뉴스보다 안전성 검토가 함께 따라붙습니다.

일반 사용자는 아직 대기

여러 보도는 더 넓은 공개가 앞으로 몇 주 뒤 가능하다고 전하지만 확정 일정은 아닙니다. 이번 호에서는 정식 출시가 아니라 제한 프리뷰와 규제 신호로 다룹니다.

02 Main 선정 이유: 에이전트 API 표준

Gemini Interactions API, 모델 호출보다 ‘상태 있는 에이전트 실행’을 기본값으로 만든다

Google은 Interactions API를 Gemini 모델과 에이전트를 위한 기본 인터페이스로 일반 제공한다고 발표했습니다. 단일 엔드포인트에서 모델 호출, 원격 샌드박스 에이전트, 백그라운드 실행, 도구 조합, 멀티모달 생성까지 다루게 만든 것이 핵심입니다.

원격 Linux 샌드박스

Managed Agents는 한 번의 API 호출로 원격 Linux 샌드박스를 마련해 코드 실행, 웹 탐색, 파일 관리를 수행합니다. Antigravity agent가 기본으로 제공됩니다.

background=True

긴 작업은 서버에서 비동기로 돌릴 수 있습니다. 채팅 응답 하나를 기다리는 구조보다 에이전트 작업 큐에 가까워졌습니다.

도구 결과도 이미지로

Google Search, Maps, 사용자 함수 같은 도구를 한 요청에서 섞을 수 있고, 도구 결과가 텍스트뿐 아니라 이미지도 반환할 수 있습니다.

기존 generateContent는 유지

Google은 legacy API도 계속 지원한다고 밝혔지만, 장기 실행 모델과 에이전트의 프런티어 기능은 Interactions API에 더 많이 실릴 것으로 봅니다.

02 Main 선정 이유: Git 작업면 변화

GitHub Desktop 3.6, 커밋·충돌·워크트리를 에이전트 시대의 기본 도구로 다듬었다

커밋 메시지가 지침을 읽음

Desktop의 Copilot 커밋 작성은 `.github/copilot-instructions.md`와 `AGENTS.md`를 반영하고 저장소의 commit metadata rules도 존중합니다.

충돌 설명 후 사람이 승인

병합 충돌이 생기면 Copilot이 충돌 변경을 설명하고 해결안을 제안합니다. 사용자는 검토하고 수락하거나 수정한 뒤 머지를 끝냅니다.

macOS·Windows에서 사용

03 Dev 선정 이유: 리뷰 비용·품질

Copilot 코드 리뷰, rg와 view 같은 파일 도구로 더 싸고 집중적으로 본다

Copilot code review는 내부 파일 탐색을 Copilot CLI와 SDK의 `grep`, `rg`, `glob`, `view` 도구로 옮겼습니다. GitHub는 기존 워크플로 변화 없이 리뷰 비용 효율을 높였고, 같은 품질 기준을 유지하며 약 20% 비용 감소를 관찰했다고 밝혔습니다.

커스텀 파일 탐색 도구 교체

코드 리뷰 경로에서 별도 도구 대신 CLI와 SDK의 기본 파일 도구를 씁니다. 에이전트가 필요한 파일을 찾는 방식이 일반 개발자 도구와 가까워졌습니다.

Medium 깊이 표기

20% 비용 감소 관찰

03 Dev 선정 이유: 팀 내부 에이전트 운영

Hugging Face Moon Bot, Slack 스레드를 기억하는 내부 코딩 에이전트 패턴을 공개했다

Hugging Face는 Slack 안에서 코드 질문, 로그·DB 조회, PR 생성, 정기 보고를 처리하는 Moon Bot 구현기를 공개했습니다. 핵심은 화려한 UI가 아니라 세션 로그, 권한 단계, 샌드박스 실행, 좁은 쓰기 권한을 실제 운영 조건에 맞춘 점입니다.

Slack 스레드가 세션

각 Slack thread가 독립 Pi agent session으로 연결되고, HF Bucket의 JSONL 파일로 대화와 도구 호출이 이어집니다. 며칠 뒤 follow-up도 같은 맥락에서 재개됩니다.

응답마다 trace 링크

응답 본문과 세션 파일을 Bucket에 올려 Slack 메시지에서 바로 열 수 있게 했습니다. 에이전트가 어떤 도구를 불렀는지 추적 가능한 구조입니다.

Okta 기반 접근 단계

쓰기 권한은 별도 통로

PR 작성은 에이전트 쉘의 토큰이 아니라 bot process의 좁은 GitHub App 토큰으로 처리합니다. 프롬프트 인젝션과 권한 누수를 줄이는 운영 패턴입니다.
